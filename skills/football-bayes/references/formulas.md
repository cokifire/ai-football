## 1. 基础分布

**泊松**
```
P(k; λ) = e^(−λ) · λ^k / k!
```

**Dixon-Coles 低分修正** `tau(i, j, lh, la, rho)`，ρ 固定 **−0.03**
```
tau(0,0) = 1 − λh·λa·ρ
tau(0,1) = 1 + λh·ρ
tau(1,0) = 1 + λa·ρ
tau(1,1) = 1 − ρ
其它      = 1
```
> ρ 做过 2-D 联合拟合，两次都触发边界解，已弃用。固定 −0.03。

**比分矩阵**
```
raw(i,j) = P(i;λh) · P(j;λa) · tau(i,j)
sc(i,j)  = raw(i,j) / Σ raw           （归一化，maxk = 12）
```

**三路与派生**
```
h = Σ_{i>j} sc      d = Σ_{i=j} sc      a = Σ_{i<j} sc
btts = Σ_{i>0, j>0} sc
ou[L] = Σ_{i+j > L} sc      L ∈ {1.5, 2.5, 3.5, 4.5}   ← float 键！
T = λh + λa
```

## 4. xG 桥接

### 同联赛（比率桥接）
```
λ_主 = (xG_主^w · xGA_客^w) / LG^(2w−1) · f_主
λ_客 = (xG_客^w · xGA_主^w) / LG^(2w−1) · f_客
```
- `w = 1.0` → `λ = xG_主 × xGA_客 / LG`（比率桥接，默认）
- `w = 0.5` → `λ = √(xG_主 × xGA_客)`（几何平均，**有偏**：会把 λ 往联赛均值拉，系统性低估强队）

### 跨联赛
```
进攻强度_i = xG_i / LG_i
防守漏洞_i = xGA_i / LG_i
λ_主 = 进攻强度_主 × 防守漏洞_客 × LG_ref × f_主
λ_客 = 进攻强度_客 × 防守漏洞_主 × LG_ref × f_客
```
`LG_ref` 基准 **1.65**，扫 {1.40, 1.50, 1.65, 1.80, 1.90}。

### 主客场拆分收缩（α）
```
x_adj = x_season × (x_split / x_season)^α        α 基准 0.25
```

### 转化率因子
```
f = 0.7 × 联赛转化率 + 0.3 × (本队进球 / 本队 xG)
```

### 联赛基线
```
LG        = ΣxG / Σ队场
联赛转化率 = Σ进球 / ΣxG
每场总进球 = 2 × Σ进球 / Σ队场
```

### 桥接 w 的逐场回测（**每场必做**）
```
predicted = Σ_matches (xG_i × 对手赛季xGA/场)^w / LG^(2w−1)
```
与实际进球对比，扫 w ∈ {0.5, 0.75, 1.0}。

## 6. 亚洲盘

`ah(res, L)`：**L 是给主队的让球数，正号 = 主队受让**。

```
d = i − j + L
w = Σ_{d>0} sc       l = Σ_{d=0} sc
整线:  ah = w + l/2
半线:  ah = w + l/2  （取 b+0.5 那条）
1/4线: ah = 0.5·(w1 + l1/2) + 0.5·(w2 + l2/2)   （在 b 与 b+0.5 之间）
3/4线: ah = 0.5·(w1 + l1/2) + 0.5·(w2 + l2/2)   （在 b+0.5 与 b+1 之间）
```

| 想要 | 调用 |
|---|---|
| 主队让 L 球覆盖 | `home_giving(res, L)` = `ah(res, −L)` |
| 客队受让 +L 覆盖 | `away_receiving(res, L)` = `1 − ah(res, −L)` |
| 主队 DNB | `ah(res, 0)` |

**校验恒等式**（写进报告）
```
客受让 +0.5 = 客胜 + 平                  （半线两侧互补）
主 −0.5     = 主独胜
主 −1.0     = 主赢2+ + 主赢1 × ½
主 −1.5     = 主赢2+
```

## 7. 市场

### 去水
```
单机构： (1/h) / (1/h + 1/d + 1/a)   然后逐机构平均
水位：   1/h + 1/d + 1/a − 1
```

### 隐含 λ 反推
```
share = m_主 / (m_主 + m_客)
在 T 上做网格搜索（1.5 → 6.0，步长 0.02），固定 share，最小化
  (model.h − m_主)² + (model.d − m_平)² + (model.a − m_客)²
→ (λh, λa, T, 残差)
```

### 等效 Elo 差（很有用的诊断量）
```
等效差 = 400 · log10( (1 − share) / share )
```
拿它和真实 Elo 差比：差 8 分 = 市场与 Elo 高度一致；差 200 分 = 两个评级体系对某队定位根本不同。

### 市场自检
```
1X2 反推的 O2.5  vs  O/U 直接去水的 O2.5
差 >5pp  → 市场内部口径不一致，写进 §10
```

## 8. EV

```
普通盘口： EV = p × o − 1
让 1 球 AH： EV = w2 × (o − 1) − (d + a)     ← 赢盘按净赔率结算
```

**门槛**：名义 EV ≥15% 才值得观察；≥100% 视为模型失效警报。
**注意**：跨机构挑价的最佳赔率会让 EV 偏高，必须标注"上界"。

## 9. 剧本四分

```
A = Σ_{i−j ≥ 2} sc    主队两球+
B = Σ_{i−j = 1} sc    主队一球胜
C = Σ_{i=j}     sc    平局
D = Σ_{j−i ≥ 1} sc    客队取胜
A + B + C + D = 100%   ← 必须校验
```
